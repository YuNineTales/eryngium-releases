# ERYNGIUM — 배포 빌드

도트 그래픽 해전 게임 **ERYNGIUM**의 실행 파일 배포 전용 저장소입니다. 소스코드는 포함하지 않습니다.

## 내려받기

[Releases](https://github.com/YuNineTales/eryngium-releases/releases) 에서 최신 버전을 받으세요.

| 플랫폼 | 파일 | 실행 |
| --- | --- | --- |
| Windows (64비트) | `ERYNGIUM-Windows-x64.zip` | 압축을 풀고 폴더 안의 `ERYNGIUM.exe` 실행 (exe만 따로 옮기면 실행되지 않음) |
| macOS (Apple Silicon) | `ERYNGIUM-macOS-arm64.zip` | 압축을 풀고 `ERYNGIUM.app` 실행 (Intel Mac 미지원) |

- 서명이 없는 빌드라 Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 누르세요.
- macOS에서 "손상됨" 또는 "확인되지 않은 개발자" 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안에서 허용하세요.
- 키보드와 마우스 전용입니다.

시험 빌드이므로 버그가 있을 수 있습니다.
